# Provider badges

Flat round badges drawn for this project as plain SVG: a solid circle in the
provider colour with a simple white glyph (✻ Claude, >_ Codex, ✦ Gemini).
They are not the providers' official logos; they stay legible at the 18 px size
used on name tags. Served locally so offline use and canvas/video capture do
not depend on a third party.
